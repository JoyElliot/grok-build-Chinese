# 代理仪表盘

代理仪表盘列出此 pager 进程中的每个顶层会话——包括本地会话和分叉——并按状态分组。在一个界面中，你可以查看、回复、附加、置顶、重命名、停止会话，或分派新代理。子代理不会单独列出；它们在父代理下运行，而父代理已经显示工作正在进行。

它不是代理模态框（`/config-agents` / `/agents`——定义和 persona）、会话选择器（`/resume` / `Ctrl+R`——磁盘上的过往对话），也不是工作流运行 UI（`/workflow runs`）。

---

## 打开仪表盘

- **grok-zh dashboard** — 让 TUI 直接进入仪表盘。
- **/dashboard**（别名 **/agents-dashboard**、**/sessions**）— 在会话内部打开。
- **Ctrl+\** — 与斜杠命令相同的视图。

最小模式下隐藏。设置 GROK_AGENT_DASHBOARD=0 或 [dashboard].enabled = false 可禁用。

---

## 你会看到的内容

```text
 Grok Build · Dashboard — 4 agents · 2 awaiting
▌● reviewer · audit token flow    Awaiting your input            2m
 ● implementer · fix login bug    Running: cargo test           12m
 ⋅ refactor · feat/login          Responding…                   24m
 ○ housekeeping                   idle                           1h
 ● implementer · add login tests  8 tools · 1.2k tok            14m
╭─────────────────────────────────────────────────────────────────╮
│ ❯ Dispatch a new agent                                          │
╰─ dispatch ──────────────────────────────────────────────────────╯
 ↑/↓ select (peek) · Enter open · Ctrl+R rename · Ctrl+T pin · Ctrl+X stop · ? help · Esc new
```

**标题栏**显示新智能体将使用的 Git 分支和工作目录，右侧为状态计数。点击位置或按 `Ctrl+L` 选择其他目录，也可在分派框输入 `/cd <path>`。

**操作行**包括默认选中的“新建智能体”，右侧为“打开历史会话”（仅工作区仪表盘）和工作树开关。列表聚焦或分派框为空时，左右方向键沿这些项目移动并停在两端；输入文字后则编辑草稿。搜索模式下即使输入为空，也按编辑查询处理。Vim 的 `l`/`h` 要求列表聚焦，搜索模式下不执行。Enter 执行当前操作，Esc 回到新建智能体；也可点击，或使用 `/resume`、`Ctrl+W`。Git 仓库中启用工作树后，下次分派会在新工作树中创建智能体。

置顶行在两种分组模式下都保持手动顺序，不因活动或更新时间而移动；使用 `Shift+↑` / `Shift+↓` 重排。

每一行都是一个顶层代理。按状态排序（Needs input → Working → Idle → Inactive → Completed → Failed）时，同一状态的行会相邻；也可以按工作目录排序（Ctrl+G 切换）。**Inactive** 是仅名册中的会话，由其他 pager 进程拥有而本进程尚未加载——属于后台噪声，因此该部分**默认折叠**（使用 → 或点击展开）。

为便于扫描 **Idle**，只显示最近的空闲代理——最新的 8 个，以及过去一小时内曾活跃的代理。其余代理折叠到底部组中的 **“N more”** 行；选中后按 Enter / →（或点击）展开，按 ← 再次折叠。Idle 标题始终显示真实总数。筛选或搜索处于活动状态时会暂停折叠。

状态图标与 Grok Build 的其他会话列表一致：

- ⋅/:/⸬/⁙ — **Working** 的动画旋转符号
- ● — **Needs input**、**Completed**、**Failed**、**Blocked** 的实心圆（颜色依次为黄/绿/红/琥珀）
- ○ — **Idle** 和 **Inactive** 的空心圆

即使某一回合已经结束，只要仍有实时后台工作，该行就保持 **Working**——例如后台任务、monitor 或活动的 /loop。活动行会说明仍在运行的内容（例如 1 monitor · 2 loops still running）。

按状态分组时显示可折叠的分区标题；每行的图标和颜色也表明所属状态。

分派输入使用与代理视图相同的提示外观。按 Ctrl+/ 可切换到**搜索模式**：❯ 前缀变为黄色的 Search:，输入会实时筛选列表，而不是分派任务。

## 按键绑定

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓、j / k | 在行和分节标题之间导航（选中行会打开 peek） |
| → / ←（在分节标题上） | 展开/折叠分节（vim 模式下为 l / h） |
| Enter（在分节标题上） | 切换分节折叠/展开 |
| Enter（空回复） | 全屏打开选中的代理（详情视图） |
| Ctrl+S | 发送 peek 回复并打开代理（或分派并附加新会话） |
| Shift+Enter / Alt+Enter | 在回复/分派输入中换行 |
| 1–9 | 当 peek 显示选项时回答待处理的权限/ask 问题 |
| Enter（已输入回复） | 向选中的代理发送/排队回复 |
| / | 将字面量 / 输入提示框 |
| Ctrl+/ | 切换搜索模式（实时筛选行） |
| Ctrl+R | 重命名选中的行 |
| Ctrl+T | 置顶/取消置顶 |
| Ctrl+G | 切换分组方式（状态 ↔ 目录） |
| Ctrl+X | 取消正在运行的回合；或在 2 秒内按两次以永久删除 |
| 悬停并点击 [✗] | 永久删除空闲/完成的行（再次点击确认） |
| Shift+↑ / Shift+↓ | 重新排列置顶行 |
| Esc | 后退一步：取消搜索 → 关闭 peek → 清除筛选 → 取消分派输入焦点 → 取消选中行 → 退出。绝不会清除已输入的分派草稿（使用 Ctrl+U / Ctrl+C 清除） |
| Ctrl+\ | 从详情视图返回，或退出仪表盘 |
| Ctrl+.（备用：?） | 键盘快捷键速查表。当 Ctrl+. 无法发送时，页脚显示 ?。列表聚焦或草稿为空时，单独按 ? 打开帮助 |

按状态分组时，每个组有一个**分节标题**（例如 Working、Idle）及 ▸/▾ 标记。选中标题并按 → / ← 可展开或折叠（vim 模式下为 l / h）。点击可切换；悬停时会变亮。只要仪表盘保持打开，折叠状态就会记住。**Inactive** 每次 pager 启动时都默认折叠；展开后会一直保持到退出。

打开一行会在**详情视图**显示对话。直接复用会话自身的单行标题，不另加标题带：最前面是智能体名称（无名时省略），后接分支和目录；常规状态右侧是 `‹ 2/5 ›`（只有一个智能体时隐藏）以及 `[Dashboard]`。按键作用于附加的智能体；Esc / Ctrl+\ 或 Dashboard 按钮返回仪表盘，`‹`/`›` 切换智能体。Esc 仅返回，`/exit` 则关闭会话并显示“会话已关闭”。

只要启用了仪表盘，每个会话的标题都显示 Dashboard 按钮，不仅限从仪表盘打开的会话；点击等同 Ctrl+\。禁用仪表盘后也移除此按钮。

详情视图中的 Ctrl+X 取决于状态。**回合正在运行时**，它会取消回合（与 Ctrl+C 相同，包括保留子代理提示），绝不会关闭会话。否则——**空闲**、斜杠命令正在执行，或取消仍在等待——Ctrl+X 会启动确认：在 2 秒内再次按下以关闭会话并返回仪表盘。其他任意键都会取消确认；若窗口内有回合开始，确认按键会改为取消回合。（如果 Ctrl+X 在终端上同时是速查表绑定，请在详情视图使用 Ctrl+.。）

参见[键盘快捷键](03-keyboard-shortcuts.md#agent-dashboard)。

## 完成或关闭会话

没有“标记完成”命令。行状态由代理推导：

- **Completed** / **Failed**：工作自行结束时（回合完成且没有仍在运行的后台任务、monitor 或 /loop）。
- 回合运行时按一次 **Ctrl+X** 会取消回合。
- 按两次 **Ctrl+X**（间隔不超过 2 秒）会**永久删除**会话（与 /delete 相同）。悬停在空闲/完成行上会将年龄替换为 [✗]，再次点击确认。
- 在详情视图中，/exit 也会关闭会话（Esc 只返回）。附加的代理内部使用 /delete 会清除该会话并返回仪表盘。

没有手动完成标志。使用 /exit 可离开会话而不删除历史。

## 分派输入

底部文本区**始终会生成新会话**。选中的行只是导航光标，不是回复目标——要与代理交流，请打开该代理。

- 自由文本 → 创建以该提示为初始内容的新顶层会话。文本不会被当作筛选器（即使以 /、s:、a: 或 # 开头）；筛选通过 Ctrl+/ 搜索模式进行。前导 / 会运行 pager 全局斜杠命令。
- 空输入 → 打开选中的行；如果焦点在 [+ New Agent]，则创建新代理。

输入后按 Ctrl+S 会分派并附加；普通 Enter 留在仪表盘，以便连续分派多个会话。Shift+Enter / Alt+Enter 插入换行；输入框随草稿增长（达到上限后滚动）。

空提示或仅含空白的提示会被忽略。超过 64 KiB 的提示会以 toast 拒绝。

### 焦点：输入栏 ↔ 概览列表（Tab）

有两个焦点区域：**分派输入**和**概览列表**。Tab 在两者之间切换；非活动输入会使边框变暗并隐藏光标。

打开时，如果至少存在一个代理，焦点默认在**概览列表**（因此 ↑/↓ 或 vim 的 j/k 可立即导航）。没有代理时，焦点停留在**分派输入**。无论哪种情况，光标都会位于 [+ New Agent]（不会预先选中代理行）。

- **输入聚焦：**输入新会话提示。提示为空时，↑/↓ 导航行；不为空时，移动光标。Esc 取消输入焦点并回到列表（保留草稿）。
- **概览聚焦：**↑/↓（以及 vim 的 j/k）在行之间移动。Enter 打开高亮代理（在 [+ New Agent] 上则发送已输入草稿或创建新会话）。Esc 留在列表并逐步后退——清除筛选，然后取消选中（→ [+ New Agent]），再退出。Tab、vim 的 i 或任何可打印字符都会回到输入框。

## Peek 面板

选中代理行后，**peek 面板**会替代分派框。没有选中行（[+ New Agent] 或按 Esc 后）时，分派框恢复。选中行即可与现有代理交流；取消选择即可开始新会话。

从上到下依次为：标题（**最近响应类型**——Thinking / Thought / Response / Edit / Read / Bash / …——以及**时间**）、最近响应（自动换行，最多约 3 行；截断时显示 …），以及实时的 ❯ reply 输入。

选中代理的**模型**以及在 always-approve（yolo）模式下的 **always-approve** 标志位于面板底部边框（与分派框相同的徽章位置），回答问题时也会显示。列表行不再重复模型或 always-approve 徽章。

**Shift+Tab 会循环切换 peek 代理的模式**（Normal → Plan → Auto（启用时）→ Always-approve → Normal），作用于**实时代理**。在分派框上，Shift+Tab 只会为*下一个*代理暂存模式。

与分派（仅限新会话）不同，peek 回复会**与选中的代理对话**：

- **在 ❯ reply 中输入后按 Enter**发送。空闲代理会立即启动；忙碌代理会将消息排队（与代理视图提示相同）。Ctrl+S 会回复并打开详情视图；Shift+Enter / Alt+Enter 插入换行（回复会随草稿增长）。
- 空回复 + Enter 会打开代理。
- 一旦回复有内容，↑/↓ 会移动光标。为空（或通过 Tab 取消焦点）时，↑/↓ 会**切换选中的代理**——面板跟随切换，并清除半输入草稿，避免发送给错误的代理。（回复中有草稿时，使用 Tab 切换到列表导航。）
- **Esc 取消选中**：先清除已输入回复，然后取消选择并将焦点置于 [+ New Agent]。
- **Tab** 在回复和行列表之间切换焦点；可打印字符会重新聚焦回复。
- 完整提示编辑器（与分派/代理提示相同）：多行粘贴芯片、鼠标选择、单词导航、Ctrl+A/Ctrl+E、Alt+Backspace、Ctrl+W/Ctrl+U/Ctrl+K、撤销、Shift+方向键选择、Ctrl+Shift+V 内联粘贴。**@** 打开以**peek 代理工作目录**为根的文件选择器；下拉菜单浮在面板上方。仪表盘快捷键（Ctrl+X 停止、Ctrl+T 置顶、Shift+↑/↓ 重排等）在面板打开时仍优先。
- 存在待处理的**权限/ask-tool**问题时，❯ reply 会隐藏，改为显示选项列表。↑/↓ **高亮**，Enter **回答**，1–9 可直接回答。自由文本 **No / reject** 和 ask-tool 的 **Other** 行接受输入的回答。多问题 Ask 表单逐个进行（(i/N)）；多选表单需要在代理自己的视图中操作。

在非常短的终端上，面板可能无法容纳；即使选中了行，也会保留分派框。

## 搜索/筛选（Ctrl+/）

Ctrl+/ 切换搜索模式，使普通输入始终执行分派。前缀从 ❯ 变为黄色的 Search:；每次按键都会实时筛选列表。

- Enter — 确认：保留筛选并返回分派提示。
- Esc 或 Ctrl+/ — 取消：清除筛选并退出搜索。
- ↑ / ↓ — 在筛选后的行中导航。

前缀（仅在搜索模式内）：

- a:<name> — 代理标签（不区分大小写的子字符串；persona/角色）。
- s:<state> — 行状态：working、idle、completed、failed、needs-input、blocked 以及同义词（busy/running/done 等）。
- #<text> — 在 #<text> 上做子字符串匹配（标签中的字面 #）。
- 其他任何内容 — 在标签和工作目录上做子字符串匹配。

## 持久化

用户级偏好位于 ~/.grok/config.toml 的 [dashboard] 下：

```toml
[dashboard]
enabled = true
grouping = "state"   # or "directory"
pinned   = ["top:<session_id>", "sub:<parent_session_id>:<child_session_id>"]
reorder  = ["top:<session_id>"]
```

置顶/重排条目使用**会话 ID**（而非按进程分配的代理槽位），因此重启后仍会保留。
