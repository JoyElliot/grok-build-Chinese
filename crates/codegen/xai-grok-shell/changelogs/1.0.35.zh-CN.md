# 1.0.35 — 2026-09-16

## 问题修复

- **无界面模式的 MCP 状态报告**及连接提醒现在与服务器的实际握手状态保持一致。
- **MCP 工具搜索和调用**现在会在守护进程路径中显示查询、结果、参数和输出。
- **Swift 字符串插值**包含嵌套括号时，现在可以在终端界面中正确高亮。
- **`--minimal` 模式下的复制粘贴**不再插入多余空行，也不会在折行位置截断长路径。
- **`/memory` 弹窗**现在会显示复制确认、搜索笔记内容，并可在窄终端中使用。
- **删除记忆**的速度大幅提升；在配置禁用记忆的会话中切换记忆开关时，现在也会正确更新智能体状态。

## 性能优化

- **语法高亮**在处理大型 TypeScript 文件等内容时，内存占用显著降低，运行速度也更快。
