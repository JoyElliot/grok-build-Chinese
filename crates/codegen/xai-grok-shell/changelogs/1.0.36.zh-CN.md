# 1.0.36 — 2026-09-17

## 新功能

- **新增 Dashboard 预览设置**，可在 Dashboard 上隐藏所选会话的预览面板。
- **新增策略设置**，允许组织禁用非托管策略来源的 hooks。
- **后台 Shell 命令**现会以实时任务行显示，并流式输出。

## Bug 修复

- **`grok --sandbox`** 在接受文件夹信任时不再退出。
- **Dashboard 中已固定的智能体**在活动状态变化时不再跳动位置。
- 含三引号字符串的 **Swift 代码**现在可在分页器中正确高亮。
- config.toml 现已接受**大小写混用的 reasoning_effort** 值（例如 "xHigh"）。
- **修复意外的空智能体会话**：从 Dashboard 发送后立刻按 Enter 不再误开空会话。
- **修复默认 TUI 会话**：config.toml 中设置的 [agent] 现会被遵守，而不再总是使用内置 plan。
- **MCP 插件认证**对在清单中声明 client ID 的服务器现可成功完成。
- 来自后台子代理的 **Shell 命令审批**现会显示，而不再被静默拒绝。
