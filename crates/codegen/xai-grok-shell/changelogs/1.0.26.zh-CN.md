# 1.0.26 — 2026-09-09

## 新功能

- 对子智能体发送的**即时插话消息**现在会打断长时间的后台等待，使消息立即送达。
- 回滚区中的**子智能体消息行**现在会标明消息采用即时插话、排队还是引导方式发送。
- **反馈表单**现在可以直接在精简模式中使用，无需切换到全屏。

## Bug 修复

- **`/btw` 旁支提问**现在会包含输入框中附加的图片。
- **后台任务提醒**不再回显原始 Shell 命令。
- **失败的后台任务**在模型读取输出后不再产生重复提醒。
- 压缩期间出现的 **TPM 速率限制错误**现在会重试，不再被误判为上下文溢出。
- 在轮次开始不久按 **Ctrl+C** 时，现在可以正确回退提示，不再发生竞态。
- **仪表盘方向键**现在可以从空输入框导航操作行。
- 针对旧版服务器的 **MCP 工具调用**现在会正确声明引导交互支持。
- **记忆 v2**现在可以从初始化失败中恢复，并避免反复出错后采集停滞。
