# 1.0.29 — 2026-09-11

## Bug 修复

- 界面中的 **Tab 导航**现在会在输入框、回滚区和整个停靠面板之间顺畅循环，不再逐个停在每个停靠分区。
- **Ctrl+G** 现在可以隐藏或显示停靠面板；隐藏后焦点返回回滚区。
- 多个并发的 **`grok agent stdio` 进程**使用同一个 GROK_HOME 时，不再在启动阶段崩溃。
- **MCP 服务器连接**不再因服务器采用 2026-07-28 协议版本而失败。
- 修复 Windows 未启用 Client-ProjFS 可选功能时出现的**启动崩溃**。

## 性能优化

- **智能体仪表盘**在只有空闲加载动画或隐藏行时，不再浪费 CPU 重绘相同帧。
