# 1.0.16 — 2026-09-01

## 中文社区版改进

- Windows 可选命令接管入口先检测官方版；没有官方版时直接安装并接管，有官方版时可选择保留或卸载。卸载不创建备份，聊天记录、登录信息和配置继续保留。
- 更新下载完成后保留完整进度条，并显示“已完成，用时 XX 秒”。
- 补全三平台 Cargo 宿主构建缓存，减少构建脚本和过程宏的重复编译。

## 破坏性变更

- **企业策略**现在可以通过已签名的 `requirements.toml` 限制用户可选择的模型。

## 新功能

- **MCP 服务器**现在可以在会话绑定时提供，以支持工作区集成。

## Bug 修复

- **长时间运行的会话**在网络问题期间因令牌过期而中断时，不再丢失工作。
- **名称很长的斜杠命令建议**不再在下拉菜单中显示空白标签。
- **创建子智能体后立即发送消息**时，不再因子智能体仍在启动而失败。
- **扩展弹窗**（`/mcps` 和其他标签页）内的加载动画现在可以正常播放。
- 从 `/mcps` 触发的 **MCP 服务器 OAuth 身份验证**不再导致会话死锁。

## 性能优化

- **长时间运行的子智能体和任务输出等待**默认上限从十分钟延长到一小时。
