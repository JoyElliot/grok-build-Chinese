# 社区版隐私策略

社区版在构建时关闭辅助数据上传。该策略优先于本地配置、环境变量、组织 requirements 和服务端功能开关；不需要设置退出遥测的环境变量。

## 已关闭

- 产品事件、Mixpanel 事件与用户资料同步、Sentry 崩溃报告。
- 内部及外部 OTLP 导出，包括用户配置的收集器；Computer Hub 的 trace、日志和指标捐赠。
- 自动 trace、会话附件、图片副本、工作区环境、工具状态、诊断和 heap profile 上传。直接、代理、签名 URL 与 S3 路径均受策略约束。
- 自动反馈请求、反馈轮次和信号同步、手动反馈提交及反馈归档上传。`/feedback` 会提示改用本仓库 Issue。
- 自动云端会话注册、历史写回、标题和 fork 元数据同步。只存在于云端的会话不能再依靠这些通道自动恢复。

`grok-zh trace <session-id>` 始终回退到本地导出，不会因配置 `trace_upload = true` 而上传。已存在的上传队列和缓存配置也不能绕过最终存储入口的策略检查。

## 仍会联网的功能

- 模型推理：提示、模型需要的上下文和工具结果仍发送给所选模型服务商。
- 登录、权限与账户查询、模型列表、公告与译文、社区更新，以及用户请求的联网工具、MCP 和插件。
- 用户主动 `/share` 会公开上传选定会话。其存储路径与后台 trace 分离，不会开启自动上传队列。
- 用户显式启用的远程控制仍通过 Relay 同步会话；Relay 默认关闭。启用后相关内容会离开本机。

本地会话、日志和配置仍保存在共享的 `~/.grok` / `GROK_HOME`。本策略只适用于本次构建的 `grok-zh`；同目录中的官方程序、其他版本或插件拥有各自的网络行为。

## 账户数据保留

`/privacy` 显示服务端账户的数据保留与训练偏好。社区版不伪造该状态，也不会自动修改账户已有设置。需要调整服务端偏好时，用户仍可在该设置中明确选择退出；设置成功后才更新本地缓存。

账户偏好无法重新启用本地上传策略，也不代表模型服务商不会处理正常推理请求。该改动不承诺删除此前上传的数据或改变服务端的处理方式。

## 维护

策略常量集中在 `xai-grok-product`，运行时入口负责停止任务，最终存储和反馈入口负责拒绝旁路调用。共享的普通文件存储接口保留用户请求所需功能；`TraceExportConfig` 默认禁止上传，仅显式会话分享使用独立用途。

方案参考 [Gork 的隐私补丁](https://github.com/thedavidweng/gork-build/tree/7f253a1e05d2ccbd6a4b2326c0aa8d01bff71244/patches)，在本项目当前源码中独立实现。未引入其补丁队列、品牌、发行或更新器方案。

后续合并上游时需要重新检查新增上传入口。构建通过只证明编译和所选检查通过；真实账户下的流量验收应使用隔离测试数据，覆盖 TUI、无头模式、会话恢复及远程控制的不同状态。
